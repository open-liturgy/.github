# Open Liturgy

Small, free, open-source tools for the Church, published at [palli.site](https://palli.site). *Palli* (പള്ളി) means church.

| Project | What it is |
| --- | --- |
| [This Sunday](https://sunday.palli.site) · [source](https://github.com/open-liturgy/thissunday) | One page for the coming Sunday in the Malankara Orthodox Syrian Church: the readings, the Gospel explained, a reflection and one question for the family. |
| [palli.site](https://palli.site) · [source](https://github.com/open-liturgy/palli.site) | The landing page that lists every project. |

## Help out

Fix a reading note, translate a Sunday or improve a site. Start with the [This Sunday contributing guide](https://github.com/open-liturgy/thissunday/blob/main/CONTRIBUTING.md), or [report a correction](https://github.com/open-liturgy/thissunday/issues/new?template=content-correction.yml) when you spot a mistake.
